01 / THE FOUNDATIONS

A little theory, then a problem.

LINEAR ALGEBRA

Vectors and dot products

A vector groups numbers together. A dot product multiplies matching entries and adds the results:

\[\mathbf{x}^{\mathsf T}\mathbf{w}=\sum_{j=1}^{d}x_jw_j.\]

A linear model can turn features into a prediction using \(\hat y=\mathbf{x}^{\mathsf T}\mathbf{w}+b\).

Try a dot product →

CALCULUS

Derivatives and gradients

A derivative describes local change. A gradient collects the partial derivatives of a function of several variables:

\[\nabla f=\left(\frac{\partial f}{\partial x},\frac{\partial f}{\partial y}\right).\]

For a differentiable function with a nonzero gradient, a sufficiently small step in the negative-gradient direction decreases the function.

Calculate a gradient →

PROBABILITY

Condition on what you know

Conditional probability restricts attention to the event you know has happened:

\[P(A\mid B)=\frac{P(A\cap B)}{P(B)},\qquad P(B)>0.\]

In a finite, equally likely sample space, count the outcomes in both events and divide by the number of outcomes in the conditioning event.

MACHINE LEARNING

Fit a model by reducing loss

For labelled pairs \((x_i,y_i)\), our small model predicts \(\hat y_i=wx_i\). Its mean squared error measures disagreement with the target values:

\[J(w)=\frac{1}{n}\sum_{i=1}^{n}(wx_i-y_i)^2.\]

Choose a learning rate \(\eta\), compute the derivative, and update \(w\leftarrow w-\eta J'(w)\).

EXERCISE 1 · VECTORS

A three-dimensional dot product

Let \(\mathbf{x}=(1,2,3)\) and \(\mathbf{w}=(4,-1,2)\). Compute \(\mathbf{x}^{\mathsf T}\mathbf{w}\).

Reveal a hint

Multiply the first entries, then the second entries, then the third entries. Add the three products.

Reveal the worked solution
\[1\cdot4+2\cdot(-1)+3\cdot2=4-2+6=\boxed{8}.\]

The result is one number, not another three-dimensional vector.

EXERCISE 2 · GRADIENTS

Differentiate one variable at a time

For \(f(x,y)=x^2+3y^2\), find \(\nabla f(1,2)\).

Reveal a hint

When differentiating with respect to \(x\), treat \(y\) as constant, and vice versa.

Reveal the worked solution
\[\frac{\partial f}{\partial x}=2x,\qquad \frac{\partial f}{\partial y}=6y.\]
\[\nabla f(1,2)=(2\cdot1,6\cdot2)=\boxed{(2,12)}.\]

EXERCISE 3 · CONDITIONAL PROBABILITY

A fair die with extra information

A fair six-sided die is rolled. Given that the result is even, what is the probability that it is greater than 3?

Reveal a hint

After conditioning on an even result, the possible values are 2, 4, and 6.

Reveal the worked solution

Let \(A=\{4,5,6\}\) and \(B=\{2,4,6\}\). Their intersection is \(\{4,6\}\).

\[P(A\mid B)=\frac{2/6}{3/6}=\boxed{\frac{2}{3}}.\]

EXERCISE 4 · OPTIMISATION

Take one gradient-descent step

Minimise \(J(w)=(w-3)^2\). Starting at \(w_0=0\), use a learning rate \(\eta=0.1\) to find \(w_1\).

Reveal a hint

Compute \(J'(w)=2(w-3)\), then use \(w_1=w_0-\eta J'(w_0)\).

Reveal the worked solution
\[J'(0)=-6,\qquad w_1=0-0.1(-6)=\boxed{0.6}.\]

The loss decreases from \(J(0)=9\) to \(J(0.6)=5.76\).

03 / INTERACTIVE GRADIENT DESCENT

See what the slope and intercept actually do.

This lab uses a straight-line model

\[\hat y=ax+b.\]

The parameter \(a\) is the slope (the model weight) and \(b\) is the intercept (the bias). Each choice of \(a\) and \(b\) produces a different fitted line and therefore a different error.

1 · PREDICT

Use the current line

\[\hat y_i=ax_i+b.\]

For every observed input \(x_i\), the line gives a predicted value \(\hat y_i\).

2 · MEASURE ERROR

Mean squared error

\[J(a,b)=\frac1n\sum_{i=1}^{n}(ax_i+b-y_i)^2.\]

Squaring makes positive and negative residuals contribute positively. A smaller MSE means the line is closer to the data overall.

3 · FIND THE GRADIENT

Which way increases the loss?

\[\frac{\partial J}{\partial a}=\frac{2}{n}\sum x_i(\hat y_i-y_i),\qquad \frac{\partial J}{\partial b}=\frac{2}{n}\sum(\hat y_i-y_i).\]

The two derivatives tell us how sensitive the loss is to the slope and the intercept.

4 · STEP DOWNHILL

Gradient-descent update

\[a\leftarrow a-\eta\frac{\partial J}{\partial a},\qquad b\leftarrow b-\eta\frac{\partial J}{\partial b}.\]

The learning rate \(\eta\) controls the step size. With a suitable learning rate, repeated updates reduce the loss; a rate that is too large can make it grow.

Geometric picture. Imagine a surface whose horizontal coordinates are \(a\) and \(b\), and whose height is \(J(a,b)\). The gradient points uphill. Gradient descent moves in the opposite direction, toward lower loss.

What should I notice while experimenting?
  • Changing \(a\) rotates the line because it changes the slope.
  • Changing \(b\) shifts the line vertically because it changes the intercept.
  • A visually better fit normally produces a smaller MSE.
  • With a sensible learning rate, repeated gradient steps reduce the loss and move the line toward the data.
  • A learning rate that is too large can overshoot and make the loss grow or oscillate.

PYTHON · SAME ALGORITHM

Gradient descent for linear regression

The browser lab above uses the same mathematics as this NumPy implementation. The code is shown after the theory so each line has a mathematical meaning.

import numpy as np

# Example data: approximately y = 4x + 1
x = np.array([0.00, 0.25, 0.50, 0.75, 1.00, 1.25, 1.50, 1.75, 2.00])
y = np.array([1.10, 2.10, 2.80, 4.20, 5.10, 5.80, 7.20, 7.90, 9.10])

# Start with a deliberately poor line
a = 1.0
b = 0.0
eta = 0.08

for step in range(200):
    y_hat = a * x + b
    error = y_hat - y

    # Partial derivatives of mean squared error
    da = (2 / len(x)) * np.sum(x * error)
    db = (2 / len(x)) * np.sum(error)

    # Gradient-descent update
    a = a - eta * da
    b = b - eta * db

mse = np.mean((a * x + b - y) ** 2)
print(f"a = {a:.4f}, b = {b:.4f}, MSE = {mse:.4f}")

EXERCISE 5 · INTERACTIVE REGRESSION

Fit the line before asking the algorithm

Use the sliders to find values of \(a\) and \(b\) that give a small MSE. Write down your values. Then reset the lab and run gradient descent. Compare your manual fit with the values found by the algorithm.

Reveal a hint

The points were generated near a line with a positive slope around 4 and an intercept around 1. Try changing one parameter at a time and watch the MSE.

Reveal the interpretation

Your exact best-fitting values need not be exactly \(a=4\) and \(b=1\), because the displayed data include small deviations from that ideal line. Least squares chooses the values that minimise the total squared residuals for the actual points.
